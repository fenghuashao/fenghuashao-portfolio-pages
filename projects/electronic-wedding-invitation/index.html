电子婚礼请柬 · Electronic Wedding Invitation

红线电影风格电子请柬：宾客端 RSVP/导航/海报/音乐 + 新人内容后台，目标受限云虚拟主机部署。

展示边界声明：本页所有内容基于仓库文档的脱敏转述，页面内不出现真实姓名、日期、地点、照片与音乐。截图位为显式占位，待用演示数据重新截图后替换。

概览

一个真实业务场景的全栈交付：红线电影风格的电子婚礼请柬。宾客端提供 RSVP 回执、场地导航、分享海报、背景音乐；新人侧提供内容后台（资料编辑、媒体管理、草稿/发布快照）。

核心功能

  • 宾客端：RSVP 回执 / 场地导航 / 分享海报生成 / 背景音乐
  • 新人后台：内容编辑、媒体管理、草稿与发布快照分离——未发布草稿不进公开接口
  • 部署方案：面向阿里云云虚拟主机（PHP 7.2 受限运行时）设计

技术架构

  • 前端 Vite + TypeScript；后端 PHP 7.2 + SQLite（pdo_sqlite），Session 鉴权
  • 受限运行时安全边界：数据库文件置于 Web root 之外；针对不支持现代部署方式的共享主机设计分阶段实现方案
  • 完整维护文档：部署参考 / 受限运行方案 / 环境清单 / 验收清单 / T1 API 合同（仓库内 8+ 份文档）

我的角色

独立开发者：产品、前后端实现、受限主机部署方案设计。

当前状态

Prototype。按仓库自述：本地原型可运行，server mode 生产验收未完成；RSVP 收集设有截止期（仓库 README 记载 2026-11-06 后停止提交）。线上真实运行状态待与本人核实后更新，本页不做预设。
