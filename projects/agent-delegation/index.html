AI Agent 任务委托系统 · pi_delegate + task-delegation

把有边界的实现任务委派给独立 agent 进程：确定性生命周期、验证证据与语义评审分离。

概览

两个配套工具，把”有边界的实现任务”从 Codex 委派给 Claude Code / pi agent 独立执行。设计原则：agent 只执行，控制平面不编造决策——机器负责确定性的生命周期与证据收集，人负责语义层面的验收。

  • task-delegation：任务生命周期框架。prepare → start → verify → review 四阶段；任务进入 accepted 需要通过确定性验证 + 显式语义 accept，两者缺一不可。
  • pi_delegate：进程级委派器。start 返回句柄，worker 独立进程续跑；支持查询、取消、续跑、取回证据。

核心特性

  • 确定性生命周期：每个状态迁移可复现、可审计
  • 验证证据与语义评审分离：机器验证（测试/命令）与人的语义判断走不同通道
  • worker 独立进程：委托方崩溃不中断被委托任务
  • 纯 Python 标准库实现，运行时零第三方依赖

技术架构

Python 3.9+ 纯标准库；通过 CLI 与 MCP 集成进 Codex / Claude Code / pi 工作流。测试规程覆盖 T0–T40，验证记录含 2026-10-10、2026-10-02 macOS 复跑与 Gate 3B 报告（仓库自述，本轮未复跑）。

我的角色

独立开发者：协议设计、两个工具的实现、T0–T40 测试规程与验证记录体系。

当前状态
