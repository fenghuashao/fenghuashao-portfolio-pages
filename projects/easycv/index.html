EasyCV · 网页复制粘贴助手

针对网页的文字选择、复制与粘贴限制提供扩展工具，通过设置与站点排除管理作用范围；展示同一测试页的前后结果。

固定版本 1.1.1；复制粘贴对照图来自自建功能演示页面，不是扩展自身界面，也不代表所有网站兼容。 观看短片与截图 ↓

实际操作与界面

为谁解决什么问题

面向需要从网页摘录文字、整理资料的用户。一些页面通过样式或事件处理阻止文字选择、复制与粘贴。EasyCV 以浏览器扩展的形式处理这些限制，并提供设置与站点排除来控制作用范围。

核心使用流程

  1. 加载扩展，按需要设置复制、粘贴与自动检测选项。
  2. 在目标页面选择文字，执行复制并粘贴到输入框。
  3. 对不希望干预的页面配置站点排除。

本页重点展示可观察的前后差异：在同一张自建限制页面上，不加载扩展时选区与结果为空；加载真实扩展后，两句示例文字被完整复制并粘贴。

我的贡献与技术决策

我负责扩展功能、设置与作用范围管理，并维护配套文档和验证流程。

  • Manifest V3 扩展结构：内容脚本处理页面限制，后台 service worker 协调扩展状态，设置页集中管理选项。
  • 样式与事件两层处理：解除文字选择样式限制，同时处理复制、粘贴等事件限制，让复制与粘贴操作真正完成。
  • 允许配置作用范围：提供复制 / 粘贴开关和站点排除；排除机制是产品的一部分。

当前状态与验证范围

展示素材锁定 GitHub 版本 1.1.1 / bbd6300，采集于 2026-11-03。它不代表其他版本的发布验收结果。
