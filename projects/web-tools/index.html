Web 工具合集 · CommitCraft · QR Code Studio · Social Preview

三个开源 Web 小工具：AI 提交信息生成、批量二维码工作台、社交分享卡片实时预览。

概览

三个面向开发者日常的小工具，全部 MIT 开源、README 完整。这是最容易直接体验的一组作品：Social Preview 有线上演示，另两个可以克隆仓库本地运行。

三个工具

CommitCraft — AI 提交信息生成器

OpenAI 驱动的规范化 Git 提交信息生成器：支持多种提交规范、历史记录管理。Vue 3 + TypeScript。

  • 仓库：github.com/fenghuashao/commit-craft

QR Code Studio — 二维码工作台

无广告的在线二维码生成器：批量生成、自定义样式、REST API。Next.js 14 + TypeScript。

  • 仓库：github.com/fenghuashao/qr-code-studio

Social Preview — 社交卡片预览器

实时预览网站在 Twitter / Facebook / LinkedIn 的分享卡片效果，一键生成 meta tags。React 18 + TypeScript。

  • 仓库：github.com/fenghuashao/social-preview
  • 线上演示：social-preview.vercel.app（README 自述部署于 Vercel；本站构建时未逐日复核可用性）
